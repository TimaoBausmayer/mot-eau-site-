Comment ça marche

Un principe simple, pensé pour devenir un vrai sport de compétition.

1

Élan

Le pilote arrive lancé, à pleine vitesse, sur la table de mise à l'eau.

2

Décollage

La moto quitte la rampe : c'est le moment où vitesse et angle deviennent décisifs.

3

Réception & chrono

Le pilote entre dans l'eau. Distance parcourue, temps réalisé : chaque run est noté.
